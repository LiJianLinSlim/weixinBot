# 艾特机器人对话

私聊文字问答：在成员配置 `private_chats` 中列出允许私聊的微信账号，同时在非空的 `bot_config.json` 收发白名单 `chat_allowlist` 中放行这些账号。重启后，开放账号直接给机器人发文字即可，无需艾特。默认不开放任何私聊账号，系统会话、自发消息和机器人回显不触发。

私聊复用模型、搜索决策和默认人格，按机器人账号及私聊对方独立保存当天最近10条输入、3轮成功回复；不借用同一人在群里的聊天。支持 `/清空` 清理当前私聊上下文、`/切换人格 名称` 单独调整私聊人格，不影响群聊。当前私聊只发送文字，不支持私聊看图或引用问答。

智能意图模式：成员配置 `smart_reply: true` 后，已启用群里不必每次 @。本地规则只放行明显叫机器人或向机器人提问/请求解释的消息，例如“怎么……”“你觉得……吗”“小管家……”。普通陈述、群友互聊和不确定的句子保持安静；该模式不调用额外模型做触发判断。

从微信成员列表真正艾特机器人，再附上问题，即可触发回复。只键入看起来像 `@昵称` 的普通文字不会触发；艾特别人也不会触发。

上下文为发言者在当前群、当天、此前最多十条有效文字，不混入其他人、其他群、控制指令和机器人的输出。回复采用本群当前人格，文字回复会真正艾特原发言者。

配置 `helper/routing_config.json` 后，先复用当前模型接口的认证调用独立云端决策模型，分别判断是否需要搜索、是否依赖上文；需要搜索时同一调用生成搜索词。独立话题不会向回答模型携带旧问答；追问保留同一发言者的相关记录。图片仍须本次明确引用或要求查看。

默认决策模型为 `DeepSeek-V4.1-Flash`，`reasoning_effort` 为 `low`，超时6秒；不加载本地模型。决策不套群人格，不改变回答模型及其回退配置。可编辑此文件的 `model`、`reasoning_effort`（`none`、`low`、`medium` 或省略）和 `timeout_seconds`（1–8秒）；接口必须支持相应参数。配置每次提问重新读取，无需重启。示例见 `routing_config.example.json`，不需要另填密钥。

用户明确要求搜索或不联网时优先遵循；决策失败或返回无效JSON时采用保守降级：明显问候直接回答，其他问题尝试搜索并保留已有语境。搜索失败仍继续回答，不声称核实了实时信息。缺少配置或 `enabled: false` 时采用该降级路径。运行日志的“问答决策”显示决策模型和两个布尔结果，不记录密钥或聊天正文。

显示名字优先使用该成员的本群绑定，未绑定时使用缓存中取得的微信名。功能需要成员记录、有效的模型配置和启用的 `mention_chat` 插件。

清空、跨天、账号切换或人格变化会取消尚未发出的旧回复。

同时启用 `voice_reply`、填写自己的 Fish Audio 配置并在群里选择音色后，回复会合成为微信语音条；成功时只发语音，合成失败时回退文字。配置和指令见[语音回复插件](../voice_reply/README.md)。
