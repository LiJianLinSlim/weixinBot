# 当前群人格

发送 `/切换人格 毒舌损友`、`/切换人格 嘴臭`、`/切换人格 卑微`、`/切换人格 夸夸` 或 `/切换人格 取消`。

“毒舌损友”以自然接话为主，适度吐槽、偶尔抽象；不要求每条都写段子，短话可以短回。会承接对上条回答的反应；认真提问仍给完整答案，不受20字限制，不捏造真人经历或聊天事实。

人格是一层表达风格，作用于当前群的模型对话、个人总结、全群总结和接龙点评。事实和接龙规则仍按任务要求处理。每个群单独保存，重启和清理聊天文本不会重置人格。

“嘴臭”使用短促、自信、直接的提示词，正文限制为二十个可见字符并使用纯文本；总结只给一句短评。其他人格遵循各自的表达要求，取消后恢复正常任务提示。

提示词位于 `wxbot_framework/personality.py`。新的公开副本没有任何预置的人格选择。

可在本机器人成员配置中设置 `default_personality` 为 `毒舌损友`，让尚未单独选择人格的群（包括以后新增的群）使用该风格。已保存的群选择优先；`/切换人格 取消` 明确恢复该群的普通风格。
